# ProtPardelle-1c browser port

Dependency-free ES modules for the released ProtPardelle-1c checkpoint families,
with a JavaScript reference and WGSL inference on WebGPU. Upstream is
[ProteinDesignLab/protpardelle-1c](https://github.com/ProteinDesignLab/protpardelle-1c/tree/ee378400f25b801fa481028000f9060183d7fb4c),
pinned to `ee378400f25b801fa481028000f9060183d7fb4c`. Original Python sources,
training configs, and examples remain unchanged. Code is MIT; published weights
are CC BY 4.0. Residue tables retain their Apache-2.0 notice in `shared/`.

The scope is the 16 checkpoints in the verified published archive: 15 structural
denoisers and MiniMPNN. All 16 running presets have original-sampler replay
fixtures, including their enabled second stages, with external full ProteinMPNN
redesign explicitly disabled. That separately downloaded designer and downstream
ESMFold/BindCraft/AlphaFold integrations are **not ported**. Secondary-structure
and adjacency-conditioned weights are unreleased. No released denoiser layer is
pruned. See [the architecture audit](docs/ARCHITECTURE.md),
[the complete sampler argument mapping](docs/MODE_COVERAGE.json), and
[machine-readable inventory](fixtures/mode_matrix.json).

## Reproduce locally

Node 22+, Python 3.12, `uv`, and a Chromium build with real hardware WebGPU are
required. Everything generated by these commands stays in this checkout.

```bash
mkdir -p .cache/tmp .cache/uv .cache/npm
export UV_CACHE_DIR="$PWD/.cache/uv"
export TMPDIR="$PWD/.cache/tmp"
uv venv --python python3.12 .venv
uv pip install --python .venv/bin/python -r tools/requirements-export.txt
npm ci --cache .cache/npm
.venv/bin/python tools/download_weights.py
.venv/bin/python tools/audit.py
.venv/bin/python tools/export_protpardelle.py
.venv/bin/python tools/export_constants.py
.venv/bin/python tools/dump_oracle.py
.venv/bin/python tools/dump_minimpnn.py
.venv/bin/python tools/dump_parser.py
.venv/bin/python tools/dump_inputs.py
.venv/bin/python tools/dump_sampler.py
npm test
npm run test:cpu
npm run test:gpu
node tools/summarize.mjs
```

The downloader verifies the publisher's MD5 and the committed SHA-256 lock before
extracting regular files. Archive SHA-256:
`a2a0f391816bea98fe61596f9b3f722162646ea3e392d81d210b5d3fa5c22014`.
The initial download is 4,294,232,741 bytes. Weights, environments, browser state,
and caches are ignored by Git. Missing weights, fixtures, or hardware fail tests.
`PORT_VARIANT` and `PORT_PRESET` are diagnostic filters; unset both for full gates.

On the ARM64 NVIDIA GB10 machine, the harness uses
`/home/ruh/.cache/ms-playwright/chromium-1243/chrome-linux-arm64/chrome`.
Set `CHROME_PATH` to override it. Its working flags are:

```text
--headless=new --no-sandbox --disable-gpu-sandbox --ozone-platform=headless
--enable-unsafe-webgpu --ignore-gpu-blocklist --enable-features=Vulkan
--use-angle=vulkan --use-vulkan=native --disable-vulkan-surface
--enable-dawn-features=vulkan_enable_f16_on_nvidia

```

The adapter must have a hardware vendor and must not be a fallback, SwiftShader,
or llvmpipe adapter. An initial null adapter is retried briefly because this occurs
on the tested Chromium/GB10 combination. Test and demo servers bind loopback port
**0**. Browser profiles, XDG directories, and temporary files stay in the checkout.
Each browser test uses a fresh profile: reusing the profile exposed a Chromium
download crash on this build. The harness also isolates the headless process
from the host desktop D-Bus/AT-SPI session. Compute remains NVIDIA Vulkan WebGPU.

## Runtime API

```js
import { createProtpardelleEngine } from './webgpu/index.js';
import { chainLayout } from './shared/inputs.js';
import { toPDB } from './shared/structure.js';

const layout = chainLayout([64], 200);
const engine = await createProtpardelleEngine({
  baseUrl: '/weights', variant: 'cc58_epoch416', precision: 'int8',
  cache: 'cache', // 'none', 'cache', or 'opfs'
  onProgress: console.log,
});
try {
  const result = await engine.sample({ ...layout, numSteps: 200 });
  const pdb = toPDB({ ...layout, ...result });
  console.log(result.timingMs, engine.memoryUsage(), pdb);
} finally {
  engine.destroy();
}
```

`denoise(input)` accepts flat `Float32Array` atom37 coordinates `[L,37,3]`,
`noiseLevel[L]`, `seqMask[L]`, `residueIndex[L]`, and `chainIndex[L]`, with optional
`cropCond`, `selfCond`, and `hotspotMask`. `sequence(input)` evaluates MiniMPNN;
its checkpoint is `cc58_epoch97_minimpnn`. Sequence inputs can include
`seqSelfCond[L,21]`, `seqCropCond[L,21]`, and replayed `neighborIndices[L,K]`.
`K=min(32,L)`. The sampler lazily loads MiniMPNN when needed.

`sample` returns `coords`, `aatype`, `atomMask`, `timingMs`, and optional
`intermediates`. Coordinates are in Å. Backbone sampling returns glycine token
indices and backbone atom masks, as upstream does. Calls handle one protein or
multichain complex; sample a collection sequentially with the same engine.

| Sampling option | Meaning |
| --- | --- |
| `numSteps`, `stepScale`, `schedule` | EDM steps, Euler scale, `{sMin,sMax,rho}` schedule |
| `sChurn`, `sTMin`, `sTMax`, `noiseScale` | Churn strength, interval, noise multiplier |
| `sidechainMode`, `jumpSteps`, `uniformSteps` | MiniMPNN and atom73 superposition or uniform atom37 steps |
| `aatype` | Known sequence token indices |
| `temperature`, `topP`, `disallowAAs` | Sequence sampling controls; defaults omit Cys and unknown |
| `skipMPNNProportion`, `annealSequence` | MiniMPNN start fraction; linear/cosine/no resampling anneal |
| `motif` | Parsed `structure`, `sourceIndices`, `targetIndices`, crop `strategy`, `translation`, optional source `hotspots` |
| `conditioning` | Crop, recurrence, reconstruction/replacement enable flags, windows, guidance schedule, scale, loss weight |
| `tipAtomConditioning` | Restrict reconstruction/replacement to tip atoms |
| `partial` | `{structure,rewindSteps,repack}` for partial diffusion/refinement |
| `initialCoordinates`, `dummyFillMode` | Supplied initial state; `zero` or `CA` dummy atoms |
| `stage2` | Second-stage overrides with `rewindSteps`, preserving the PDB rounding boundary |
| `replay` | Ordered typed random draws, checked for kind, shape, and complete consumption |

`parseStructure(text,{format:'pdb'|'cif',chainResidueGap})`, `tokenize`,
`selectPositions`, `contigToPlacement`, and `chainLayout` implement the input
utilities. Contig integer draws can be supplied explicitly. Chain-gap zero uses
local chain indices; use each checkpoint's recorded `config.data.chain_residx_gap`.

The CPU factory is `createProtpardelleCPU({baseUrl,read})` from `cpu/index.js`;
its URL points directly at `weights/<variant>/<precision>`. `read(url)` returns
an `ArrayBuffer`. Both implementations use the same graph and sampler drivers.
`shared/`, `cpu/`, and `webgpu/` have no npm dependencies or Node imports. Every
learned GPU operation and reconstruction derivative is WGSL; browser CPU work
handles parsing, random draw preparation, schedules, command encoding, and I/O.

An optional supplied `device` remains alive after `destroy()`. Self-created
devices are destroyed. Destruction is idempotent; temporaries are freed in
`finally` after success, failure, or cancellation. `memoryUsage()` distinguishes
resident and transient buffers. Buffer sizes are checked against both WebGPU
limits before allocation. Scratch storage is reused across denoiser blocks.
`useF16` may request `shader-f16`; F16 storage still has a core
`unpack2x16float` path and F32 accumulation. I8 uses packed four-byte words and
per-output-row scales. Neural activations remain F32.

`webgpu/worker.js` is a real module-worker RPC entry point with `load`, `sample`,
`denoise`, `sequence`, `cancel`, and `destroy`. Output array buffers are transferred.
Avoid concurrent calls on an engine. Cancellation reaches sampling step boundaries.

## Verification boundaries

The reference runner executes the original model classes and sampler, with all
attached modules explicitly in evaluation mode. It stores actual Gaussian arrays,
categorical inverse-CDF uniforms, annealing decisions, contig integers, each
denoiser's inputs and block traces, MiniMPNN inputs/graph/block traces, coordinate
gradients used by guidance, and all trajectory states. It does not assume equal
random-number streams from equal seeds across languages.

Arithmetic checks use `<1e-4` relative RMS against the **same exported storage
precision reloaded into PyTorch**. Sequence and atom-mask checks are exact.
Quantization error against original FP32 is reported separately. Complete
sampler runs use their own intermediate coordinates. MiniMPNN's internal traces
are additionally checked at its recorded original input boundary because its
degenerate quaternion feature is discontinuous; see the audit for the reproduced
PyTorch behavior. This is not a claim that every freely running MiniMPNN hidden
state stays within the same tolerance after a discontinuous feature decision.

The direct coordinate-gradient diagnostic in `tools/dump_gradient.py` is stricter
than the sampler cases: arbitrary dense random atom37 clouds can amplify FP32
rounding in the Jacobian above `1e-4`. Running `node tools/check-gradient.mjs`
records this separately in `fixtures/gradient_diagnostic_metrics.json` and exits
nonzero if the threshold is exceeded (3/9 CPU cases, maximum `4.37e-4`);
the public sampling validation includes the gradients actually used in every
reconstruction-guided fixture. Numerical parity alone is not a validation of
foldability, designability, or experimental function. Replay trajectories are
short correctness fixtures, not biological-quality benchmarks.

## Demo and vendor contract

`npm run demo` prints an ephemeral loopback URL. Open it in a hardware-WebGPU
browser. The demo includes precision and mode controls, input files, progress,
cancellation, a rotatable Cα trace, PDB/FASTA downloads, and Release GPU. It runs
the model in a module worker. No hosted inference service is used.

```bash
node sync-upstream.mjs .cache/vendor-smoke
node sync-upstream.mjs .cache/vendor-smoke --write
```

The vendor tool copies only `shared/`, `cpu/`, `webgpu/`, `LICENSE`, and this guide.
It rejects symlink inputs and source-directory overwrites. Weights, fixtures,
Python, dependencies, and caches are excluded.

Proposed `denovo.run` mapping:

| Artifact | Port mapping |
| --- | --- |
| `StructureArtifact` input | PDB/mmCIF parsing; motif or partial-diffusion structure and residue mapping |
| `SequenceSet` input | Known `aatype` arrays, one sequence per generated complex |
| `ResidueTrack` input | Fixed positions, hotspots, chain indices, motif-placement masks |
| `StructureArtifact` output | Coordinates, canonical atom names, atom mask, sequence, chain/residue metadata, PDB |
| `SequenceSet` output | Sampled FASTA and optional MiniMPNN log probabilities |
| `ResidueTrack` output | Motif indices, masks, per-residue logits from requested intermediates |
| `Collection` | Repeated independent calls with separate replay tapes and shared resident weights |

Preserve variant, storage precision, upstream commit, schedule, motif mapping,
sequence constraints, and replay identity in artifact provenance. Downstream
folding/design evaluation belongs to its own integration.
